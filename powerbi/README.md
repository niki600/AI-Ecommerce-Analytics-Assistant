# Power BI Dashboard

## E-Commerce Sales Dashboard

This folder contains the Power BI dashboard developed for the **AI E-Commerce Analytics Assistant** project.

### Files

- **Dashboard_Final_v3.pbix** – Power BI dashboard file containing interactive visualizations and analysis.
- **Dashboard_Final.pdf** – Complete dashboard preview in PDF format.

### Dashboard Insights

The dashboard provides insights into key e-commerce business metrics, including:

- Total Revenue
- Total Orders
- Total Customers
- Monthly Revenue Trends
- Sales Performance Analysis

### Tools Used

- Power BI
- DAX
- Data Visualization
- E-Commerce Sales Data
