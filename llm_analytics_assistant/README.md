# LLM Analytics Assistant

This folder contains the core implementation of the AI-powered analytics assistant for the E-Commerce Analytics project.

The application uses a Large Language Model (LLM) to understand user queries related to e-commerce data and assist in generating meaningful analytical insights.

## Features

- Natural language query processing
- AI-powered data analysis
- Database interaction and query execution
- Automated insight generation
- Interactive analytics assistance
- Integration of processed e-commerce data with the LLM

## Project Files

- `app.py` - Main application file
- `database.py` - Handles database connections and operations
- `llm_service.py` - Manages communication with the Large Language Model
- `requirements.txt` - Contains the required Python dependencies
- `test_connection.py` - Tests the database connection
- `test_llm.py` - Tests the LLM integration

## Workflow

1. The user provides a query in natural language.
2. The LLM interprets the user's request.
3. Relevant data is retrieved from the database.
4. The data is processed and analyzed.
5. The system generates meaningful insights and responses.

## Technologies Used

- Python
- Large Language Models (LLM)
- SQL
- Database Integration
- Pandas

## Purpose

The goal of this module is to make e-commerce data analysis more accessible by allowing users to interact with data using natural language instead of writing complex SQL queries manually.
