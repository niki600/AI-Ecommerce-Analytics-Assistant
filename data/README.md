# Data

This folder contains the datasets used for the E-Commerce Analytics project.

## Dataset

The project uses the Brazilian Olist E-Commerce dataset, which includes information related to:

- Customers
- Orders
- Order Items
- Products
- Sellers
- Payments
- Customer Reviews
- Geolocation
- Product Categories

## Processed Data

The `processed` folder contains cleaned, transformed, and analysis-ready datasets generated during the data preprocessing and analysis stages.

These processed datasets are used for:

- Sales Analysis
- Customer Analysis
- Product Analysis
- Payment Analysis
- Delivery Analysis
- Customer Review Analysis
- Regional Performance Analysis
- Power BI Dashboard Development
- AI-Powered Analytics Assistant

## Data Processing

The raw datasets were cleaned and transformed using Python before being used for further analysis and visualization.
