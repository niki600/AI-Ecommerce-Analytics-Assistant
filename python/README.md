# Python Data Analysis

This folder contains Python scripts used for data cleaning, preprocessing, feature engineering, and exploratory analysis of the e-commerce dataset.

## Key Analysis Areas

- Data Cleaning and Preprocessing
- Data Profiling and Quality Analysis
- Sales and Revenue Analysis
- Customer Analysis
- Product and Category Analysis
- Delivery Performance Analysis
- Payment Analysis
- Customer Review Analysis
- Business Feature Engineering

## Key Libraries

- Pandas
- NumPy

The processed datasets generated through these scripts are stored in the `data/processed` directory.
