# SQL Analysis

This folder contains SQL scripts used to analyze the e-commerce dataset and extract meaningful business insights.

## Key Analysis Areas

- Sales and Revenue Analysis
- Customer Analysis
- Order Analysis
- Product and Category Analysis
- Seller Analysis
- Payment Analysis
- Delivery Performance Analysis
- Customer Review Analysis

## SQL Operations Used

- SELECT Statements
- WHERE Clauses
- JOIN Operations
- GROUP BY and HAVING
- Aggregate Functions
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions

The SQL queries in this folder are used to explore the dataset, analyze business performance, and generate insights for the e-commerce analytics project.
